 2 핵심 테이블 
 work 작품 (애니/게임) 
 컬럼 타입 제약 설명 
 id BIGINT PK, AUTO_INCREMENT 작품 ID 
 title VARCHAR(255) NOT NULL, INDEX 제목 
 type VARCHAR(20) NOT NULL ANIME / GAME (enum) 
 synopsis TEXT NULL 줄거리 
 release_date DATE NULL, INDEX 출시·방영일 
 season VARCHAR(20) NULL, INDEX 분기 (예: 2026-spring) 
 rating DECIMAL(3,1) NULL 평점 
 image_url VARCHAR(500) NULL 포스터 
 studio_id BIGINT FK → studio.id, NULL 제작사 
 external_id VARCHAR(50) UNIQUE 외부 API ID (중복수집 방지) 
 source VARCHAR(20) NOT NULL JIKAN / RAWG (출처) 
 created_at / updated_at DATETIME NOT NULL BaseTimeEntity 
 character 캐릭터 
 컬럼 타입 제약 설명 
 id BIGINT PK 캐릭터 ID 
 name VARCHAR(255) NOT NULL, INDEX 이름 
 image_url VARCHAR(500) NULL 이미지 
 work_id BIGINT FK → work.id, NOT NULL 소속 작품 
 studio 제작사 · genre 장르 
 테이블.컬럼 타입 제약 
 studio.id / genre.id BIGINT PK 
 studio.name / genre.name VARCHAR(100) NOT NULL, UNIQUE 
 work_genre 작품-장르 (N:M 조인) 
 컬럼 타입 제약 
 work_id BIGINT FK → work.id, PK(복합) 
 genre_id BIGINT FK → genre.id, PK(복합) 
 3 회원 · 즐겨찾기 
 member 회원 
 컬럼 타입 제약 설명 
 id BIGINT PK 회원 ID 
 login_id VARCHAR(50) UNIQUE, NOT NULL 로그인 아이디 
 password VARCHAR(255) NOT NULL BCrypt 해시 
 nickname VARCHAR(50) NOT NULL 닉네임 
 role VARCHAR(20) NOT NULL USER / ADMIN 
 created_at / updated_at DATETIME NOT NULL 가입·수정 시각 
 favorite 즐겨찾기 (Member ↔ Work) 
 컬럼 타입 제약 설명 
 id BIGINT PK ID 
 member_id BIGINT NOT NULL, INDEX 회원 (※ MSA 대비 ID 참조) 
 work_id BIGINT NOT NULL, INDEX 작품 (※ ID 참조) 
 created_at DATETIME NOT NULL 찜한 시각 
 UNIQUE 제약 (member_id, work_id) 복합 UNIQUE → 같은 작품 중복 찜 방지. 
 4 인덱스 · 설계 노트 
 테이블 인덱스 목적 
 work title, release_date, season, type 목록 필터·정렬 
 work UNIQUE(external_id) 외부 API 중복 수집 방지(upsert) 
 favorite UNIQUE(member_id, work_id) 중복 찜 방지 
 member UNIQUE(login_id) 아이디 중복 방지 
 ★ MSA 대비 favorite 은 member · work 를 JPA FK 연관이 아닌 ID(BIGINT) 참조 로 둔다 (DB FK 제약은 선택). 추후 서비스 분리 시 조인 의존을 줄이기 위함. (단 work 내부의 character·work_genre는 FK 사용) 
 5 Elasticsearch 매핑 (검색 전용) 
 MariaDB의 work 를 검색용으로 색인하는 WorkDocument (별도 모델). 
 필드 ES 타입 분석기 
 id keyword - 
 title text nori (한국어 형태소) + edge_ngram(자동완성) 
 characterNames text nori (캐릭터명 통합 검색) 
 genres keyword - (필터) 
 type · season keyword - (필터) 
 rating · releaseDate float · date - (정렬) 
 동기화 외부 수집( external ) 또는 work 변경 시 → WorkDocument 색인. MariaDB=원본 / ES=검색 역할 분리.
