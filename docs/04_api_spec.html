1 공통 규약

  • Base URL: /api (nginx가 백엔드로 프록시)
  • 형식: 요청·응답 모두 JSON (UTF-8)
  • 인증: Authorization: Bearer {JWT} (인증 필요 API)
  • 메서드 규약: GET 조회 · POST 생성 · PUT 수정 · DELETE 삭제
  • 페이징: ?page=0&size=20&sort=releaseDate,desc (Spring Pageable)

공통 응답 포맷 (ApiResponse)

{ "success": true, "data": { ... }, // 성공 시 데이터 "error": null // 실패 시 { code, message } }

2 auth · member (인증·회원)

메서드경로설명인증
POST/api/members회원가입-
POST/api/auth/login로그인 → JWT 발급-
POST/api/auth/reissue토큰 재발급 (선택)-
GET/api/members/me내 정보 조회🔒

예: 로그인

// 요청 POST /api/auth/login { "loginId": "haru", "password": "****" } // 응답 { "success":true, "data":{ "accessToken":"eyJ...", "nickname":"haru" } }

3 work (작품)

메서드경로설명인증
GET/api/works작품 목록 (필터: ?type=ANIME&season=2026-spring&genre=action&page=)-
GET/api/works/{id}작품 상세 (캐릭터·장르·제작사 포함)-
GET/api/works/seasons분기 목록 (선택)-

4 search (검색 · Elasticsearch)

메서드경로설명인증
GET/api/search?q={키워드}통합 검색 (제목·캐릭터·태그)-
GET/api/search/autocomplete?q={접두}자동완성 추천어-

검색은 MariaDB가 아닌 Elasticsearch를 조회 (WorkDocument).

5 favorite (즐겨찾기)

메서드경로설명인증
GET/api/favorites내 즐겨찾기 목록🔒
POST/api/favorites즐겨찾기 추가 (body: workId)🔒
DELETE/api/favorites/{workId}즐겨찾기 삭제🔒

★ Springdoc(Swagger UI) 자동 생성
컨트롤러에 어노테이션을 달면 /swagger-ui.html에서 API 문서가 자동 생성된다. 이 명세서는 *설계 단계의 계약*이고, 구현 후엔 Swagger UI가 *살아있는 문서* 역할. (하루님 롯데온 Swagger 경험과 동일!)
