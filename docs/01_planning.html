1 서비스 개요

애니메이션·게임 작품 정보를 통합 검색하고 정리·즐겨찾기하는 개인 도감 서비스. 결제·상거래가 없는 정보형 서비스로, 백엔드 핵심 역량(검색·외부 API 연동·연관 모델링)을 증명하는 데 초점.

★ 포트폴리오 셀링포인트
① Elasticsearch 통합 검색(자동완성·오타교정)   ② 외부 공개 API 연동·동기화(배치 수집)   ③ 복잡한 연관관계 모델링(작품–캐릭터–장르–제작사)   ④ 셀프호스팅 인프라(Docker·자체 운영서버 배포)

2 핵심 기능 & 범위

Phase 1
MVP · 3~4주
  • 외부 API로 애니 데이터 수집·적재 (먼저 애니 한 종류만)
  • 작품 목록 / 상세 (줄거리·캐릭터·장르·제작사)
  • 통합 검색 (Elasticsearch — 제목·캐릭터·태그)
  • 분기별·장르 필터
  • 회원가입·로그인 + 즐겨찾기
Phase 2
확장
평가·리뷰 / 인기 랭킹(Redis) / 게임 추가(동일 구조 복제) / 본 작품 기반 추천
⚠️ 완성 원칙
처음부터 애니+게임 다 만들지 말 것. 애니부터 끝까지 완성 → 게임은 같은 구조 복제로 확장. (미완성 함정 회피)

3 데이터 소스 — 무료 공개 API

크롤링 대신 합법적 공개 API로 데이터 확보. 이 외부 연동 자체가 기술 어필 포인트.

콘텐츠API특징
애니메이션Jikan API (MyAnimeList 비공식, 무료·무인증) / AniList GraphQL작품·캐릭터·성우·평점·방영분기 풍부
게임RAWG API (무료 키) / IGDB게임·장르·플랫폼·평점

※ 수집 = 스케줄러 배치로 주기 호출 → DB 적재 → Elasticsearch 색인. (API rate limit 고려해 페이징·지연 처리)

구성 요점

  • 개발(PC): IntelliJ + 로컬 Docker로 MariaDB·Elasticsearch 띄워 개발·테스트
  • 운영(맥미니): docker compose로 앱+MariaDB+ES(+Redis) 한 번에 기동. arm64 호환 이미지 사용(대부분 지원)
  • 배포: 초기엔 ./gradlew build → scp로 jar/이미지 전송 → docker compose up -d --build. 이후 GitHub Actions로 자동화 가능
  • 외부 노출: Cloudflare Tunnel 권장 — 공유기 포트포워딩 없이 HTTPS 자동, 고정 IP 불필요, 보안↑. (대안: 포트포워딩 + DuckDNS)
⚠️ 운영 유의
① 맥미니는 데모/면접 시점에 켜져 있어야 함(24/7 가정 시 전원·네트워크 안정성 클라우드보다 낮음) ② Elasticsearch는 RAM 사용 큼 → 맥미니 RAM 여유 확인(16GB+ 권장) ③ 운영 비밀번호·키는 .env로 분리(평문 커밋 금지)
★ 이것도 포폴이다
"셀프호스팅 + Docker Compose + 터널 외부공개 + CI/CD"는 인프라·DevOps 역량을 함께 증명. 백엔드 + 운영을 한 번에 보여주는 강점.
